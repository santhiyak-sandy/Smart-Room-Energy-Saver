
# Smart Room Energy Saver 💡

## Project Overview

Smart Room Energy Saver is a digital system
designed to control room lighting based on
the number of people present.

The system uses entry and exit sensors to
maintain an occupancy count and automatically
adjusts the lighting according to room usage.

## Problem Statement

Lights are often left switched on in rooms
even when they are not fully occupied.

This project explores how digital logic can
be used to reduce unnecessary energy consumption
through occupancy-based lighting control.

## Objectives

- Track the number of people in a room.
- Detect entry and exit events.
- Control lighting based on occupancy.
- Implement the system using Verilog HDL.
- Verify functionality through simulation.

## System Working

Two sensors are placed near the entrance.

The sensor sequence is used to determine
whether a person is entering or leaving.

The occupancy counter is updated accordingly.

Based on the number of people present,
the system activates the required lights.
